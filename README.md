# 📱 NBA NAAC EMS

## 📌 Description

**NBA NAAC EMS (Education Management System)** is a modern Android application designed to streamline academic data management for institutions. The app helps manage student and faculty achievements, institutional events, and NAAC-related records efficiently using **Firebase Realtime Database** and **Firebase Authentication**.

It provides real-time updates, structured data handling, and an intuitive user interface, making it suitable for institutional reporting and accreditation processes.

---

## 🚀 Features

*  Secure authentication using Firebase (Login/Register)
*  Real-time data synchronization
*  Dashboard with NAAC grade, CGPA, and statistics
*  Manage student and faculty achievements
*  Add/Edit/Delete records easily
*  Search and filter functionality for quick access
*  Smart category selection with “Other” option
*  Generate PDF reports with charts
*  Clean and user-friendly UI

---

## 🧩 Modules

### 1. Authentication Module

* Email & password-based login and registration
* Secure user authentication via Firebase
* User profile data stored in Firebase

### 2. Dashboard Module

* Displays key metrics like NAAC grade and CGPA
* Visual representation of institutional statistics

### 3. Student Achievements Module

* Add, edit, and delete student achievements
* Categorization for better organization

### 4. Faculty Achievements Module

* Track faculty publications, research, and contributions
* Structured data storage for accreditation use

### 5. Events & Workshops Module

* Manage academic events and workshops
* Store event details for future reference

### 6. Evidence Repository

* Centralized storage for records and proofs
* Search and filter capabilities for quick retrieval

### 7. Reports & Analytics

* Generate downloadable PDF reports
* Includes charts and analytics for insights

---

## 🛠 Tech Stack

* **Platform:** Android (Java)
* **Backend:** Firebase Realtime Database
* **Authentication:** Firebase Authentication
* **Tools:** Android Studio, Firebase Console

---

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/BhumireddyHarikareddy/NBA_NAAC_EMS.git
   ```

2. Open the project in **Android Studio**

3. Connect Firebase:

   * Add your `google-services.json` file
   * Enable Authentication (Email/Password)
   * Set up Realtime Database (test/production mode)

4. Sync Gradle and build the project

5. Run the app on:

   * Emulator OR
   * Physical Android device
